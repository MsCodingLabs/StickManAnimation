# 🕴️ Stickman Animation

Eine kleine, animierte Webszene mit einem laufenden Strichmännchen – komplett in **HTML & CSS** umgesetzt!

## Screenshot
![stickManAnimation.png](https://github.com/MsCodingLabs/StickManAnimation/blob/main/stickmanAnimation.png)

## ✨ Features
- **Bewegte Arme & Beine** dank CSS-Keyframes
- **Strichmännchen läuft** über eine stilisierte Straße
- **Nahtloser Übergang** in ein animiertes GIF
- **Farbverlauf-Hintergrund** für eine visuell ansprechende Szene
- **Kein JavaScript** – reine CSS-Magie!

## 🎯 Lernziele
Dieses Projekt eignet sich ideal zum Üben von:
- CSS-Animationen mit `@keyframes`
- Positionierung mit `position`, `z-index`, `transform` usw.
- Kreativer Nutzung von HTML/CSS ohne JavaScript

## 🔧 Technologien
- HTML5
- CSS3
