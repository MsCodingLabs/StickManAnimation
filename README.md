# 🕴️ Stickman Animation – Wenn CSS Beine bekommt

Ein laufendes Strichmännchen – ganz ohne JavaScript.  
Diese kleine Webszene zeigt, wie man mit reinem **HTML & CSS** Bewegung ins Spiel bringt:  
Mit `@keyframes`, Farbverläufen und cleverer Positionierung läuft die Figur über eine stilisierte Straße – minimalistisch, aber voller Dynamik.
